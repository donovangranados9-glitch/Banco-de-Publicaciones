# Banco de publicaciones analizadas

Sitio web del banco de publicaciones de Facebook analizadas en la tesina sobre imaginarios sociales en torno a la UCR. Material de apoyo visual para la exposición oral.

## Publicarlo con GitHub Pages

1. Creá un repositorio nuevo en GitHub (puede ser público o privado) y subí el contenido de esta carpeta (`index.html` y la carpeta `imgs/`) a la raíz del repositorio, o a una carpeta `docs/` si preferís.
2. En el repositorio, entrá a **Settings → Pages**.
3. En "Build and deployment", elegí **Deploy from a branch**.
4. Seleccioná la rama (por ejemplo `main`) y la carpeta (`/root` o `/docs`, según dónde hayas subido los archivos).
5. Guardá. GitHub te va a dar una URL del tipo `https://tu-usuario.github.io/nombre-del-repositorio/` en unos minutos.

## Estructura

```
index.html   → la página completa (HTML, CSS y JS en un solo archivo)
imgs/        → las 17 capturas de las publicaciones analizadas
```

No requiere build ni dependencias: es HTML estático, funciona directamente al abrir `index.html` en un navegador o al publicarlo en cualquier hosting estático (GitHub Pages, Netlify, Vercel, etc.).
