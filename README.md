# Banco de publicaciones — actualización para GitHub Pages

Este paquete trae la versión más reciente del sitio (con los cambios de los apartados 2.3 y 3.2, el texto simplificado y el botón del girasol animado).

## Qué contiene

- `index.html` — la página completa, lista para reemplazar la que ya subiste.
- `imgs/` — las 18 imágenes de las publicaciones, incluida la nueva `p-3-2-2.jpg` (el cartel de "Jaguares de Costa Rica y militantes del Partido Pueblo Soberano").

## Cómo actualizar tu repositorio

1. Entra a tu repositorio en GitHub, en la carpeta raíz donde está tu `index.html` actual.
2. Haz clic en `index.html`, luego en el ícono del lápiz (editar) o en los tres puntos y "Delete file" para borrarlo, y después usa "Add file" → "Upload files" para subir el `index.html` nuevo de este paquete. También puedes simplemente arrastrar el archivo nuevo sobre el que ya existe: GitHub te va a preguntar si quieres reemplazarlo, y aceptas.
3. Entra a la carpeta `imgs/` de tu repositorio y sube ahí únicamente el archivo `p-3-2-2.jpg` (es la única imagen nueva; las otras 17 ya las tienes subidas de antes, así que no hace falta volver a subirlas).
4. Baja hasta el final de la página de subida y escribe un mensaje corto para el commit, por ejemplo "Actualiza banco de publicaciones", y dale a "Commit changes".
5. Espera uno o dos minutos y revisa tu sitio en la URL de GitHub Pages (termina en `.github.io/...`). El refresco puede tardar un poco en verse reflejado, así que si no ves el cambio de inmediato, recarga la página forzando el caché (Ctrl+Shift+R o Cmd+Shift+R).

Si prefieres, también puedes borrar el repositorio completo y subir todo de nuevo (el `index.html` y toda la carpeta `imgs/`), siguiendo los mismos pasos que usaste la primera vez.
